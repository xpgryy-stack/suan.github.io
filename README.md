# 星洲药业 · 品牌宣传网站

单页静态站点（无构建依赖）。视觉沿用品牌方案 01「星芒」，整体走**严肃写实**路线：大图实景开场、墨青/近黑的沉稳底色、思源宋体标题、细线分割、图注与表格化的信息排布。

## 本地预览

直接双击 `index.html` 即可；或起一个本地服务（路径与字体加载更稳）：

```bash
cd xingzhou-site
python -m http.server 8778
# 打开 http://127.0.0.1:8778/
```

## 目录

```

assets/js/main.js         导航、滚动出现、表单交互
assets/img/               标识、产品包装图、favicon
assets/img/photo/         实景照片（已统一调色）

backup/                   v1 编辑风首页（留档，可对比）
```

## 图片说明（重要）

- `photo/` 里的 5 张是**占位实景图**，用于确定版式与色调，不是星洲药业的真实工厂/产品：
  - 开场图：`Landscape Scenery in Liupanshui, Guizhou, China`，作者 **云中君**，CC BY 2.5，来自 Wikimedia Commons
  - 港口图：`Port Jersey container ship sunset 2018`，作者 **Eric Kilby**，CC BY-SA 2.0，来自 Wikimedia Commons
  - 实验室 / 检验 / 厂区：Burst（Shopify）免费图库
- 上线前**必须替换为贵司实拍**（厂区、车间、包装线、实验室），并按实际拍摄补图注。
- 若保留 CC BY / CC BY-SA 图片，需在页面上署名并注明许可；商业项目建议直接换成自有素材。
- 产品包装图是按品牌系统绘制的示意稿，不是真实标签稿。
